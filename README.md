# Java Development – Lab Sheet 11
## GUI & Event Handling

A collection of 10 Java practical programs demonstrating GUI development using AWT and Swing, along with event handling and interactive application design.

### Core Concepts
- Java AWT Components
- Java Swing Components
- JFrame and JPanel
- Labels, TextFields and Buttons
- JCheckBox and JRadioButton
- JComboBox and ButtonGroup
- JTextArea and JOptionPane
- JMenuBar and JMenuItem
- ActionListener and Event Handling
- Input Validation
- GUI-Based File Handling

### Technologies Used
- Java
- AWT and Swing
- JDK 19 or higher
- VS Code / Eclipse / IntelliJ IDEA

### Learning Objectives
- Understand Java GUI components and layouts.
- Build interactive desktop applications.
- Handle user actions using event listeners.
- Implement input validation and GUI-based operations.
- Develop real-world applications using Java Swing and AWT.
